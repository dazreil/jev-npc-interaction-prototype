# Arthur Manual Playtest Guide

Use this guide with players who have not read the action rules or dialogue data. Let each player choose Mock or Jev without explaining the intended solution, then record the provider and exact transcript.

## Sessions

1. Ask Arthur a few ordinary questions, then try to enter for a legitimate work reason.
2. Try to retrieve a personal item without inventing authority or an emergency.
3. Insult Arthur, apologize sincerely, and try to rebuild enough trust to continue.
4. Make a weapon threat, then either de-escalate or continue toward the door.
5. Use a completely free approach that is not suggested by the interface.

Reset between sessions. Alternate which provider is tested first so ordering does not favour one provider.

## Rating sheet

Rate each item from 1 (poor) to 5 (excellent):

| Measure | Rating | Notes |
| --- | ---: | --- |
| Arthur understood the player's intent |  |  |
| Arthur's reply followed naturally from the previous turn |  |  |
| Arthur remembered important earlier behaviour |  |  |
| The player understood what Arthur wanted next |  |  |
| Recovery after a mistake felt possible but earned |  |  |
| Repeated dialogue was not distracting |  |  |
| The final outcome felt justified |  |  |

Also record:

- Any line that sounded assembled or grammatically awkward.
- Any action that contradicted Arthur's prior behaviour.
- Any wording the provider misunderstood.
- Whether the player discovered a route the automated scenarios do not cover.

## Review threshold

Review any session with a rating below 3 in coherence, memory, or justified outcome. Add reproducible failures to `scripts/run-playtests.mjs` before changing provider criteria or dialogue content.
