# Interface font

The complete game and developer interface uses the locally bundled `VT323-Regular.ttf` font.

VT323 is a monospaced typeface by Peter Hull designed to evoke DEC VT320 terminal glyphs. This copy comes from the Google Fonts repository and is distributed under the SIL Open Font License 1.1 included in `OFL.txt`.

Source: <https://github.com/google/fonts/tree/main/ofl/vt323>
