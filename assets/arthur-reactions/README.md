# Arthur reaction portraits

These identity-preserving portrait edits were created from `../arthur-portrait.jpg` with the built-in image-generation tool for Phase 11.

Every prompt preserved Arthur's identity, uniform, crop, camera angle, warehouse background, rain and lighting. Only the requested expression or minimal head/eye movement changed. All prompts excluded text, borders, new props and watermarks.

| Asset | Expression request |
| --- | --- |
| `blink.webp` | Both eyelids naturally closed; all other facial muscles neutral. |
| `listening.webp` | Attentive focus, slightly lifted brow and subtle concentration. |
| `suspicious.webp` | Raised brow, narrowed eyes, pressed lips and guarded attention. |
| `irritated.webp` | Impatient, tired eyes, furrowed brow and compressed lips. |
| `hostile.webp` | Controlled hostility, direct stare, lowered brow and tightened jaw. |
| `friendly.webp` | Cautiously softened half-smile, warmer eyes and relaxed brow. |
| `afraid.webp` | Controlled fear, slightly widened eyes and tense brow during a weapon threat. |
| `dismissive.webp` | Eyes turned slightly away with a final closed expression. |
| `entry-granted.webp` | Calm approval, tiny professional nod and restrained half-smile. |

The release files are 360×480 WebP images. The browser rasterizes each to a 96×72 display surface before enlarging it to 192×144, preserving the low-resolution CD-ROM treatment while keeping the full set below 256 KiB.
