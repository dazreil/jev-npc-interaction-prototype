# Arthur reaction portraits

These identity-preserving portrait edits were created from `../arthur-portrait.jpg` with the built-in image-generation tool for Phase 11.

Every prompt preserved Arthur's identity, uniform, crop, camera angle, warehouse background, rain and lighting. Only the requested expression or minimal head/eye movement changed. All prompts excluded text, borders, new props and watermarks.

| Asset | Expression request |
| --- | --- |
| `blink.png` | Both eyelids naturally closed; all other facial muscles neutral. |
| `listening.png` | Attentive focus, slightly lifted brow and subtle concentration. |
| `suspicious.png` | Raised brow, narrowed eyes, pressed lips and guarded attention. |
| `irritated.png` | Impatient, tired eyes, furrowed brow and compressed lips. |
| `hostile.png` | Controlled hostility, direct stare, lowered brow and tightened jaw. |
| `friendly.png` | Cautiously softened half-smile, warmer eyes and relaxed brow. |
| `afraid.png` | Controlled fear, slightly widened eyes and tense brow during a weapon threat. |
| `dismissive.png` | Eyes turned slightly away with a final closed expression. |
| `entry-granted.png` | Calm approval, tiny professional nod and restrained half-smile. |

The browser intentionally rasterizes each source to a 96×72 display surface before enlarging it to 192×144. Asset-size optimization remains part of the release-polish phase.
